# Antigravity on Cloud Workstations セットアップ

Cloud Workstations 上に Google Antigravity の実行環境を構築するための手順書です。
受講者のローカル PC に環境を作れない場合（クライアント端末の制約がある場合など）の代替手段として利用します。

## コンテンツ

| パス | 内容 |
| --- | --- |
| [`docs/setup-guide-ja.md`](docs/setup-guide-ja.md) | Cloud Workstations クラスタ / コンフィグ / インスタンス作成から Antigravity 起動までの手順 |
| [`docs/slides-outline.md`](docs/slides-outline.md) | 説明用スライドの構成案 |

> [!CAUTION]
> Cloud Workstations のインスタンスは起動時間で課金されます。
> ハンズオン終了後は必ずインスタンスを停止（または削除）してください。
