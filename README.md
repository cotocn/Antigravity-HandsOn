# Antigravity Hands-On

Google Antigravity を活用したエージェント開発ハンズオンの資材リポジトリです。

## ワークショップ資材

- **`workshops/gemini-enterprise-admin/starter-kit/`**
  Gemini Enterprise 管理者向けハンズオンの受講者用スターターキットです。
  受講者は `starter-kit` フォルダを直接開いてハンズオンを実施します。

- **`workshops/antigravity-cloud-workstations/`**
  Cloud Workstations 上に Antigravity 環境を構築する手順書です。
